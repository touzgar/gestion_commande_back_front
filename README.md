# Gestion Commande - DevOps End-to-End Project

## Project Overview

Gestion Commande is a full-stack web application for managing orders through a modern DevOps lifecycle.

The objective of this project is to demonstrate a complete DevOps chain from development to production monitoring.

## Functional Scope

The application allows:

- User authentication
- Product and category management
- Order management
- Frontend / Backend separation
- Database connectivity
- Monitoring of services and infrastructure

## Technical Stack

### Frontend

- React

### Backend

- NestJS / Node.js

### Database

- PostgreSQL (Neon)

### DevOps Stack

- GitHub
- GitHub Actions
- Docker
- Kubernetes (Minikube)
- ArgoCD
- Prometheus
- Grafana
